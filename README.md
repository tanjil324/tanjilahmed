# Tanjil Ahmed Shifat — Latest Portfolio

Includes looping meadow video, typing portrait, 41 projects, project carousel, animated Services, Hire Me enquiry form, and search metadata.

## Upload

Extract this ZIP first. Upload the files and folders INSIDE it, not the ZIP or its outer folder. index.html must be at the repository root.

Use the repository's "uploading an existing file" link, then commit your upload. If GitHub rejects too many files in one upload, upload the root files first, then assets in smaller batches while preserving each folder path. GitHub Desktop can also copy and commit the entire extracted folder in one operation.

## Enable GitHub Pages

Repository Settings → Pages → Deploy from a branch → main → / (root) → Save.
Wait for GitHub's Pages deployment to succeed. The expected website address is:
https://tanjil324.github.io/tanjilahmed/

## Google indexing

After the site is live, add the exact website address as a URL-prefix property in Google Search Console. Choose HTML tag verification, copy Google's tag into index.html inside <head>, commit, wait for deployment, and verify. Submit sitemap.xml and use URL Inspection to request indexing for the homepage. Google determines whether and when it appears in search.

The robots.txt in this project subdirectory does not control the github.io host root; submit the sitemap directly in Search Console.

The enquiry form prepares a draft in the visitor's email app; it does not send mail through a server. Testimonials are clearly labelled sample quotes.
